How to trust it

iPhone or iPadThis device
Download the profile
  1. Tap Allow, then open Settings and tap Profile Downloaded → Install.
  2. Open Settings → General → About → Certificate Trust Settings.
  3. Turn on outpost {{.Domain}}, then come back here.
MacThis device

With outpost on this Mac, one command does it all: outpost gateway trust {{.Address}}

Download the certificate
  1. Open the file. Keychain Access adds outpost {{.Domain}}.
  2. Double-click it, open Trust, and set When using this certificate to Always Trust.
  3. Close the window and enter your password.

A Mac needs Always Trust even after installing the profile: the profile alone doesn't trust it for websites.

Firefox or ZenThis browser
Download the certificate
  1. Open Settings → Privacy & Security, and under Certificates click View Certificates.
  2. On Authorities, click Import and pick the file.
  3. Tick Trust this CA to identify websites, then click OK.

These browsers keep their own list, so they need this even after the system trusts it.

AndroidThis device
Download the certificate
  1. Open Settings → Security → More security settings → Encryption & credentials.
  2. Tap Install a certificate → CA certificate, and pick the file.
WindowsThis device
Download the certificate
  1. Open the file and click Install Certificate, then choose Local Machine.
  2. Choose Place all certificates in the following store → Trusted Root Certification Authorities, and finish.
LinuxThis device
